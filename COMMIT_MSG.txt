Text blocks: a No-frame option and per-block font/size/colour editing

- Add a "No frame" text style — the text sits straight on the section
  background, taking the section's text colour by default.
- Add a "Text" control to the text-block edit menu: pick the font (Sans, Serif,
  Script, Casual, Bold), the size (S/M/L/XL), and the colour (a swatch row with
  an "auto" default), plus a Reset. Choices apply over whatever frame is chosen
  and preview live in the editor.
- Bundle two new typefaces for real variety: Lora (serif) and Caveat (casual
  handwriting), alongside the existing Plus Jakarta Sans and Dancing Script.

Data: CapsuleContent gains textFont / textSize / textColor; a key-stripping
setItemTextStyle writes them (and clears on reset, so Firestore never sees
undefined). TextFrame and NoteEditor take a bodyOverride so the read view and
the editor stay in sync.

Verified on web: app mounts with both new fonts loaded; No frame renders with no
card; Serif/L/blue apply live (Lora_500Medium, 18px, #4f6f99) and Reset restores
the frame defaults.
